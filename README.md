# Neon-Pong-A-Modern-Twist-on-the-Classic-Arcade-Game
Neon Pong is a modern, visually enhanced version of the classic Pong arcade game. Built with simplicity and smooth gameplay in mind, this project blends retro mechanics with colorful neon visuals for an engaging gaming experience.  The game features responsive paddle controls, making it fun for both casual players and arcade lovers.
